# Grove Blocks covers

Original vector promotional artwork generated from the game's palette, plant illustrations and a real board state after 12 placements (seed 20260926). The dashed shape is a legal next-placement preview; the floating piece matches it.

- Landscape: 1920 × 1080 PNG
- Portrait: 800 × 1200 PNG
- Square: 800 × 800 PNG

Regenerate from the repository root with `node scripts/create-covers.mjs`. Rendering uses the installed Microsoft Edge through Playwright. The HTML files are self-contained vector sources, with no external assets or fonts.

Cover lettering contains only the game title and its descriptive subtitle, Garden Puzzle. These assets do not include the gameplay preview videos required separately by CrazyGames.
